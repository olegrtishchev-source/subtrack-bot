# 🤖 SubTrack Bot — Умный трекер подписок

VK-бот для анализа регулярных платежей и подписок. Учебный проект, разработанный с соблюдением принципов чистой архитектуры, паттернов проектирования и лучших практик Python-разработки.

## 🚀 Особенности проекта

- **Чистая архитектура (Clean Architecture):** Четкое разделение на слои:
  - *Controller* (`bot/handlers.py`) — обработка команд и клавиатур.
  - *Service* (`services/bank_api.py`) — бизнес-логика и работа с внешними данными.
  - *Repository/Model* (`models/database.py`) — работа с базой данных.
- **Mock-сервер вместо реального API:** Имитация банковского сервиса с эмуляцией сетевых задержек (`asyncio.sleep`) и случайных ошибок. Это демонстрирует навык работы с абстракциями и тестирования устойчивости системы.
- **Интерактивный UI:** Использование кастомных клавиатур VK для удобной навигации вместо ввода текстовых команд.
- **База данных (SQLite + Peewee ORM):** Хранение пользователей, подписок и полной истории запросов.
- **Надежное логирование (Loguru):** Структурированное логирование всех событий, ошибок и действий пользователя в JSON-формате.
- **Типизация:** Полная аннотация типов (`typing`) для всех функций и переменных.

## 🛠 Технологический стек

| Категория | Технологии |
| :--- | :--- |
| **Язык** | Python 3.12 |
| **VK API** | `vk_api` (Long Polling), `VkKeyboard` |
| **База данных** | SQLite, ORM `Peewee` |
| **Логирование** | `loguru` (JSON format, rotation) |
| **Конфигурация** | `python-dotenv` |
| **Асинхронность** | `asyncio` (для эмуляции сетевых запросов) |

Требования
Python 3.10+
Учетная запись ВКонтакте и созданное сообщество (бот)
Шаг 1: Клонирование и установка зависимостей
# Создайте виртуальное окружение
python -m venv .venv

# Активируйте его (Windows PowerShell)
.\.venv\Scripts\Activate.ps1

# Установите зависимости
pip install -r requirements.txt
Шаг 2: Настройка переменных окружения
Создайте файл .env в корне проекта и добавьте туда свои данные:

VK_BOT_TOKEN=ваш_токен_сообщества_vk
GROUP_ID=ваш_id_группы_без_минуса
DEBUG_MODE=True
Где взять токен?

Зайдите в управление сообществом ВК.
Раздел "Работа с API" -> "Ключи доступа".
Создайте ключ с правами "Доступ к сообщениям сообщества".
Шаг 3: Запуск бота
python main.py
После запуска бот начнет слушать сообщения. Зайдите в сообщество ВКонтакте и нажмите кнопку «Начать» или любую кнопку меню.

🎮 Как пользоваться
Бот оснащен интуитивным меню с кнопками:

💰 Самая дорогая — анализирует подписки и показывает самую затратную (с логотипом и датой).
📉 Самая дешевая — находит самую экономную подписку.
📜 История — показывает последние 5 запросов пользователя с временными метками.
❓ Помощь — выводит справку по возможностям бота.
Примечание: Бот работает с тестовыми данными (Mock), эмулируя ответ банка.

🏗 Архитектурные решения
Почему Mock-сервер?
В учебном проекте использование реального банковского API невозможно из-за требований безопасности и отсутствия публичной «песочницы». Вместо этого реализован класс MockBankAPI, который:

Соблюдает интерфейс BaseBankAPI (принцип Dependency Inversion).
Эмулирует сетевые задержки и случайные ошибки (5% шанс).
Позволяет протестировать сценарии обработки ошибок без риска реальных потерь.
Это позволяет в будущем заменить одну строчку кода (MockBankAPI() на RealBankAPI()) без переписывания всей логики бота.

Обработка асинхронности
Так как библиотека vk_api является синхронной, а имитация банка использует async/await для эмуляции сети, применен паттерн запуска асинхронной функции внутри синхронного контекста через asyncio.run(). Это эффективный компромисс для проектов такого масштаба.
